# Number Guessing Game
A simple command-line game built with Python. The computer picks a secret number, and you keep guessing until you get it right.

## How to run
1. Install Python 3
2. Download 'number_guessing_game.py'
3. Open a terminal in that folder and run:
   'python number_guessing_game.py'

## How to play
- Enter a number between 1 and 10
- The game tells you if you are right or should try again
- It ends when you guess correctly
